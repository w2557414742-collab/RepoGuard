# 变更影响排名

## 前置知识

了解 Git 双版本差异和反向依赖。

## 模块职责、输入与输出

classify 比较名称标识、签名、内容哈希和导入表。analyze 分别遍历基线图、目标图，输出 Finding 和 ImpactReport。 [源码](../../src/repoguard/impact.py)。

## 算法、数据结构与成本

反向 BFS 保留最短路径见证。路径风险按距离、类型和不确定性衰减。主要成本为两次图构建和有界遍历。

## 验证、工程边界与练习

删除一个公开函数，依据报告定位基线的调用者。再比较仅调用边与导入边的漏报。 [测试或实测证据](../../tests/integration/test_index_and_impact.py)。
