# BM25 词法检索

基于实际源码。

## 学习目标与原理

手算罕见词、词频饱和及长度归一化。 IDF 放大罕见词，词频项与文档长短共同调整贡献。

## 源码、函数与调用

Search.hybrid 先调用 bm25，再把排序输入融合。 [bm25 · src/repoguard/retrieval.py:72](../../src/repoguard/retrieval.py#L72-L84)

- [第 78 行](../../src/repoguard/retrieval.py#L78) 中的 `for term in dict.fromkeys(tokens(query)):`。先去除重复查询词。
- [第 80 行](../../src/repoguard/retrieval.py#L80) 中的 `idf = math.log1p((len(self.symbols) - len(posting) + 0.5) / (len(posting) + 0.5))`。计算逆文档频率。
- [第 82 行](../../src/repoguard/retrieval.py#L82) 中的 `normalizer = 1.2 * (0.25 + 0.75 * self.lengths[sid] / max(self.average, 1))`。按文档长度缩放词频。

## 数据结构、复杂度与选型

倒排表 term→symbol→次数，另保存长度和平均值。 O(匹配 posting 总长)，额外空间为命中候选数。 符号名和签名是当前可解释且低成本的特征。
