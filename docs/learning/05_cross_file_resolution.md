# 跨文件导入与重导出

## 前置知识

掌握模块、命名空间包和相对导入。

## 模块职责、输入与输出

Collector.visit_ImportFrom 标准化模块路径，Resolver.imported 追踪导出绑定和子模块。 [源码](../../src/repoguard/resolution.py)。

## 算法、数据结构与成本

模块目录用哈希查找。重导出通过已访问集合和深度上限控制。增量索引记录命中与未命中的探测。

## 验证、工程边界与练习

为缺失模块补充定义，检查调用从未解析变为已解析。测试条件导入、别名和循环。 [测试或实测证据](../../tests/integration/test_index_and_impact.py)。
