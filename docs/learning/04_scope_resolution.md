# 作用域解析

## 前置知识

理解 Python 函数局部变量规则、class body、global 和 nonlocal。

## 模块职责、输入与输出

Resolver.lookup 输入作用域、名字和位置，输出绑定候选。Collector 先保存所有绑定及其可见时间。 [源码](../../src/repoguard/resolution.py)。

## 算法、数据结构与成本

在词法父作用域中查找。函数内的局部绑定遮蔽同名外部定义。单次基础查找成本随作用域深度和同名绑定数增长。

## 验证、工程边界与练习

把函数内赋值移到调用之前，再加入 nonlocal，观察目标和可信度。许多控制流候选使用保守合并。 [测试或实测证据](../../tests/unit/test_parser.py)。
