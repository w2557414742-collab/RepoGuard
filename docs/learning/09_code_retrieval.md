# 符号与代码检索

## 前置知识

理解倒排索引、BM25、RRF 和图扩展。

## 模块职责、输入与输出

Search.exact 定位符号。bm25 为词项相关度打分，hybrid 融合排序和证据路径。 [源码](../../src/repoguard/retrieval.py)。

## 算法、数据结构与成本

在名称、限定名和签名上构建词项索引。一次查询开销由查询词项的 posting 长度与排序支配，加上有界图遍历。
